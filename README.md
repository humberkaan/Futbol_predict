# Futbol_predict
Este proyecto tiene como objetivo utilizar datos reales de fútbol para analizar partidos, equipos y resultados.
Los datos reales de equipos, partidos y resultados se obtienen mediante la API de **football-data.org**.
El objetivo es utilizar estos datos para crear un modelo que permita analizar el comportamiento de los equipos y simular posibles resultados de partidos.

This project aims to use real football data to analyze matches, teams, and results. Real data about teams, matches, and results is obtained through the football-data.org API. The goal is to use this data to create a model that can analyze team performance and simulate possible match outcomes.
